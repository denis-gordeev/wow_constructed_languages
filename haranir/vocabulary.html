The *Hara-* Root

The most prominent morpheme in the Haranir corpus, appearing in five independent attestations:

Name*Hara-* ContextProposed Function
*Haranir**Hara-* + *-nir*Ethnonym: "Hara-people"
*Hara'ni**Hara'* + *-ni*Language name: "Hara-tongue"
*Harandar**Haran-* + *-dar*Toponym: "Hara-land"
*Hara'ti**Hara'* + *-ti*Faction: "Hara-group"
*Aln'hara**Aln'* + *-hara*Concept: "[Aln]-call"

Confidence: Moderate. Five attestations with consistent structural position. The *Hara-* root may mean either "people/we" (in the ethnonymic forms) or "call/song" (if *Aln'hara* provides the semantic key), or both — the semantic connection "those who hear the call" → "the called people" is coherent.

The *-dar* Toponymic Suffix

*Harandar* contains the suffix *-dar*, which also appears in Earthen (*Dornogal*) and Arathi (*Beledar*, *Mereldar*) toponyms within Khaz Algar.

If *-dar* = *-dor* (Titan "land/realm"), then *Harandar* = "Hara-land" — a toponym formed using a borrowed Titan-derived suffix. This would place Hara'ni toponymic conventions within the Khaz Algar areal sphere.

Confidence: Low–Moderate for *-dar* as a borrowed toponymic suffix. See earthen/vocabulary.html for cross-reference.

Phonological Observations

Sound Inventory

Consonants: h, k, l, m, n, ng (/ŋ/), r, t, v, y (/j/)

Vowels: a, e, i, o, u

Key Features

  • High /h/ frequency: 6 of ~15 names contain /h/ — unusually high for a WoW language
  • Medial apostrophe: Consistent compound-boundary marking
  • Geminate consonants: *Hannan* (-nn-), *Amarakk* (-kk-)
  • Syllable simplicity: Predominantly (C)V(C)
  • Vowel distribution: /a/ and /i/ predominate; /o/ and /u/ less common

Relationship to Other Languages

No confirmed genetic relationships. Hara'ni does not fit into any known WoW language family:

  • Not elven: No shared morphemes; different phonological profile
  • Not troll (Zandali): No shared morphemes despite physical similarities
  • Not titan-forged: Haranir are not titan-forged; *-dar* is likely borrowed
  • Not Aqir-descended: No confirmed shared morphemes with nerubian/qiraji

Areal features shared with Khaz Algar languages:

  • The *-dar* toponymic suffix (shared with Earthen and Arathi, likely borrowed)
  • Medial apostrophe compounding (shared with nerubian, but widespread convention)
