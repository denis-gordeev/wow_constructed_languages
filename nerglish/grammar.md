# Nerglish (Murloc/Jinyu/Ankoan/Kobyss) Grammar

## Phonology

### Murloc (Nerglish) Phonology

Murloc names are built from a restricted consonant inventory with heavy use of syllabic consonants and reduplication:

**Consonant Inventory**:

| | Bilabial | Alveolar | Velar | Glottal |
|---|---|---|---|---|
| Stops | b | | k g | |
| Fricatives | | | | |
| Nasals | m | | | |
| Liquids | | r l | | |

No complex consonant clusters from non-guttural consonants appear. Names are overwhelmingly gurgling compounds built from *mrgl-*, *glrgl-*, *mrg-* sequences.

**Syllable Structure**: Syllabic consonants dominate; no clear CV/CVC patterns. Names consist of 1–4 "beats" (e.g., *mrgl-glr*).

**Vowel Inventory**:

| | Front | Central | Back |
|---|---|---|---|
| Close | | | |
| Close-mid | | | |
| Open-mid | | ɜ | ʌ |
| Open | | | |

Restricted; mostly /ɜ/, /ʌ/ inferred from orthography. Vowels are largely absent from murloc proper names.

### Jinyu Phonology (Post-Evolution)

Jinyu naming shows a **dramatic shift** from Nerglish gurgling patterns:

**Consonant Inventory**:

| | Bilabial | Alveolar | Post-alveolar | Velar | Glottal |
|---|---|---|---|---|---|
| Stops | b | | | k g | |
| Fricatives | | | ʃ | | |
| Affricates | | | tʃ | | |
| Nasals | m | | | | |
| Liquids | | r l | | | |

Full inventory including /ʃ/ (Shushen, Shai), /tʃ/ (implied by orthographic patterns), plus the murloc inventory

**Vowel Inventory**:

| | Front | Central | Back |
|---|---|---|---|
| Close | i | | u |
| Close-mid | e | | o |
| Open-mid | | | |
| Open | a | | |

Full /a e i o u/ — all appear freely (vs. Nerglish's vowel-poor gurgling)

**Syllable Structure**: Full CV and CVC syllables (vs. Nerglish's syllabic consonants). Names range from 2–5 syllables.

Key features:
1. Full vowel inventory replaces Nerglish's restricted vowels
2. Dorsal consonants /ʃ/, /tʃ/ appear for the first time
3. Complex syllable structures replace gurgling patterns
4. Some jinyu use English compound names (Sharpfin, Waterstrider), but proper names are non-English
5. Apostrophe usage: Sele'na uses an apostrophe — unique among jinyu names but parallels Zandali and other WoW naming conventions

### Ankoan Phonology

Ankoan phonology shows continuity with jinyu with possible simplification:

1. **Continuity with jinyu**: Full vowel inventory, CV/CVC syllable structure
2. **Possible simplification**: Ankoan names tend to be shorter (2–4 syllables vs. jinyu 2–5)
3. **No apostrophes**: Unlike jinyu (Sele'na), ankoan names show no apostrophe usage
4. **Fewer attested names**: Only 5 ankoan personal names known vs. 30+ jinyu

### Kobyss Phonology

Kobyss have **no attested native phonology**. All kobyss names are Common/English compounds or descriptors (Grand Gluttony, Sharpscale the Devourer, Chieftain Gillcarver). This represents near-total language loss.

### Phonological Patterns

1. **Murloc syllabic consonant dominance**: Murloc names are built almost entirely from syllabic consonant sequences (*mrgl-*, *glrgl-*, *Brgl-*, *Gm-*). Vowels are rare and restricted to /ɜ/ and /ʌ/. This makes Nerglish unique among WoW languages — no other language uses syllabic consonants as the primary syllable nucleus. The gurgling phonological profile is likely an articulatory reflection of murloc vocal anatomy (gill-based respiration, aquatic environment).

2. **Jinyu open syllable preference**: Jinyu proper names strongly favor open (vowel-final) syllables: *Fujin*, *Kuru*, *Mari*, *Nali*, *Gorai*, *Orachi*, *Zai*, *Lu*, *Shai*, *Sahn*. Of 25+ attested jinyu names, approximately 80%+ end in vowels. This open-syllable preference contrasts with murloc Nerglish (which has no clear syllable boundaries) and parallels the elven languages' sonorant/vowel-final preference.

3. **Jinyu -shi suffix**: The element *-shi* appears in at least 5 jinyu names: *Karasshi*, *Izissha*, *Zusshi*, *Resshi*, *Husshun* (with *-shun* variant). This concentration is statistically unlikely to be coincidental — approximately 20% of jinyu names end in *-shi* or a variant. The suffix may mark an agentive, honorific, or tribal-designation function, but no confirmed gloss exists.

4. **Jinyu consonant inventory expansion from Nerglish**: The jinyu consonant inventory includes /ʃ/ (*Shushen*, *Shai*) and /tʃ/ (implied by orthographic patterns) — phonemes entirely absent from murloc Nerglish. This expansion from ~6 consonants (murloc) to ~10+ consonants (jinyu) represents the most dramatic phonological expansion attested in any WoW language family and is the only known case of a WoW language gaining phonological complexity over time.

5. **Ankoan name shortening**: Ankoan names average 2.6 syllables (range 2–4) vs. jinyu names averaging 3.2 syllables (range 1–5). The five attested ankoan names (*Okani*, *Inowari*, *Ori*, *Akana*, *Kotori*) are all CV.CV.CV or CV.CV patterns — simpler than the longest jinyu names (*Rassharom* = CVC.CV.CVC, *Ot-Temmdo* = CVC.CVCCV). This shortening trend is consistent with moderate phonological simplification over time.

6. **Kobyss total phonological loss**: Kobyss represent the endpoint of a continuous simplification trajectory: murloc (syllabic consonants) → jinyu (full CV/CVC) → ankoan (shorter CV.CV) → kobyss (no native phonology). This is the only known case of complete language loss in WoW — kobyss retain only 3 Common words ("Animate bones", "Devour", "Violence"). The trajectory from Nerglish's gurgling complexity through jinyu's full phonology to kobyss's silence is the most extreme linguistic arc in the WoW corpus.

## Morphology

### Murloc Morphology

Murloc proper names show compounding patterns built from gurgling morphemes:

| Name | Pattern | Notes |
|------|---------|-------|
| Brglmurgl | *Brgl-* + *-murgl* | Winterfin murloc |
| Gmurgl | *Gm-* + *-urgl* | Saltscale murloc |
| Mrmrglmr | *Mr-* + *-mrgl-* + *-mr* | Winterfin murloc |
| Murgurgula | *Mur-* + *-gurg-* + *-ula* | Siltfin murloc |

The morphemes *-murgl*, *-urgl*, *-gurg* may be tribal or role designators, but their meanings are entirely unattested.

### Jinyu Morphology

With only one confirmed translation (*Onoho* = "Deep Shadow"), jinyu morphology is largely unreconstructed. Possible patterns:

- **-shi** suffix: Appears in *Karasshi*, *Izissha*, *Zusshi*, *Resshi* — possibly an agentive or honorific suffix
- **Reduplication**: *Rassharom*, *Rassan* share *Rass-* — possibly a prefix or name element
- **Apostrophe compounding**: *Sele'na* is the only jinyu name with an apostrophe, suggesting this is not a productive morphological device in jinyu

### Ankoan Morphology

No morphological analysis is possible from 5 proper names. Names follow CV.CV.CV patterns (*Okani*, *Akana*, *Kotori*) consistent with jinyu naming.

### Kobyss Morphology

No native kobyss morphology exists. All names are Common/English descriptors.

## Syntax

- **Murloc**: No attested sentences; only the battle cry *Aaaaaughibbrgubugbugrguburgle!* is recorded
- **Jinyu**: Full dialogue in Common is attested, but no jinyu-language sentences are recorded
- **Ankoan**: Full dialogue in Common is attested, but no ankoan-language sentences are recorded
- **Kobyss**: Only 3 Common-language phrases attested: "Animate bones", "Devour", "Violence"

## Writing System

No writing system is attested for any member of the Nerglish language family. All names are rendered in Common/English orthography.

## Dialectal Variation

- The Winterfin murlocs of Borean Tundra speak a dialect of Nerglish "different enough from standard Nerglish to be mutually unintelligible" (confirmed). This is the only attested dialectal variation within Nerglish.

## Limitations

Nerglish grammar is almost entirely unreconstructed. The murloc → jinyu → ankoan → kobyss family provides a unique case study in WoW linguistics — both linguistic expansion (murloc → jinyu) and linguistic regression (ankoan → kobyss) — but the grammatical data for all four stages is extremely limited. The single confirmed jinyu translation (*Onoho* = "Deep Shadow") is the only native word with a known meaning in the entire family.

## Open Linguistic Investigations

### Investigation 1: Murloc → Jinyu Phonological Expansion — The Only Case of Linguistic Complexification in WoW

The Nerglish → Jinyu transition is unique in the WoW corpus as the only documented case of a language **gaining** phonological complexity over time. All other attested language changes in WoW involve simplification or divergence from a common ancestor:

| Feature | Murloc (Nerglish) | Jinyu | Direction |
|---------|-------------------|-------|-----------|
| Syllable structure | Syllabic consonants; no clear CV/CVC | Full CV/CVC syllables | Gained structure |
| Vowel inventory | Restricted (/ɜ/, /ʌ/) | Full (/a e i o u/) | +3 vowel phonemes |
| Consonant inventory | ~6 consonants | ~10+ consonants | +4+ phonemes |
| Name length | 1–4 "beats" | 2–5 syllables | Comparable |
| Apostrophe usage | None | Sele'na (1) | Gained |

This expansion is typologically unusual — most language change involves reduction or trade-offs (gaining in one area while losing in another). The jinyu expansion may reflect:

| Hypothesis | Description | Confidence |
|------------|-------------|------------|
| Physiological evolution | Jinyu evolved enhanced vocal apparatus from murloc anatomy, enabling new phonemes | **Moderate–High** — consistent with lore (jinyu are "evolved" murlocs) |
| Contact influence | Jinyu acquired phonemes through contact with Pandaren and other Pandarian species | **Low–Moderate** — possible but no direct evidence |
| Cultural development | Jinyu cultural sophistication (waterspeakers, oracles) drove phonological elaboration for ritual purposes | **Low–Moderate** — speculative |

The contrast with the jinyu → ankoan → kobyss trajectory (simplification and eventual loss) makes the Nerglish family a unique bidirectional case study: complexity increases (murloc → jinyu) then decreases (jinyu → kobyss), potentially driven by different selective pressures at each stage.

**Confidence: Moderate–High** that the phonological expansion reflects genuine in-universe evolution (physiological changes) rather than design inconsistency, given the lore confirmation that jinyu evolved from murlocs.

### Investigation 2: Jinyu *-shi* Suffix — Agentive, Honorific, or Coincidental?

The element *-shi* appears in 5+ jinyu names:

| Name | Pattern | Notes |
|------|---------|-------|
| *Karasshi* | *Kara-* + *-sshi* | "Bold" warrior |
| *Izissha* | *Izi-* + *-ssha* | "Dextrous" monk |
| *Zusshi* | *Zu-* + *-sshi* | Pet tamer / "Seeker" |
| *Resshi* | *Re-* + *-sshi* | Scrollmaker |
| *Husshun* | *Hu-* + *-sshun* | Trainee |

The variant forms *-shi*, *-sshi*, *-sha*, *-sshun* suggest a family of related endings rather than a single invariant suffix.

| Hypothesis | Description | Confidence |
|------------|-------------|------------|
| Agentive suffix | *-shi* = "one who does/Person who is"; *Karasshi* = "one who is bold" | **Low–Moderate** |
| Honorific | *-shi* = respectful name ending, similar to Japanese *-shi* (historic/academic) | **Low** — real-world resemblance may be design coincidence |
| Tribal/family marker | *-shi* = designation of jinyu tribal or family affiliation | **Low** |
| Coincidental | *-shi* is not a morpheme; the concentration is a statistical artifact of small sample | **Low–Moderate** |

**Confidence: Low–Moderate** for *-shi* as a genuine morpheme. The concentration in ~20% of jinyu names is above chance expectation, but the lack of any confirmed meaning makes all analyses speculative.

### Investigation 3: *Sele'na* — Zandali Contact or Independent Apostrophe Development?

*Sele'na* is the only jinyu name with an apostrophe. This single data point raises the question of whether the apostrophe reflects:

| Hypothesis | Description | Confidence |
|------------|-------------|------------|
| Zandali contact | The apostrophe was borrowed from Zandali naming conventions through troll-jinyu contact in Pandaria | **Low–Moderate** — both species coexist in Pandaria |
| Independent development | The apostrophe independently marks a morpheme boundary in jinyu, unrelated to Zandali | **Low** — one attestation is insufficient |
| Non-native name | *Sele'na* may not be a native jinyu name but a name acquired through contact with another species | **Low** |
| Blizzard design artifact | The apostrophe was added for aesthetic reasons without morphological significance | **Low–Moderate** — single exceptions are often design artifacts |

**Confidence: Very Low–Low** for any specific analysis of *Sele'na*. A single apostrophe name cannot establish a pattern. The Zandali contact hypothesis is the most plausible if the apostrophe is morphologically significant, given that Zandali uses apostrophes productively and both species inhabit Pandaria.
